# wengelef.github.io

Personal CV site for Florian Wengelewski, published at https://wengelef.github.io (GitHub Pages user site, served from the domain root).

## Stack
Vite + React 19 + TypeScript, Tailwind CSS v4, shadcn/ui, Magic UI components, `motion`, `simple-icons`.

## Commands
- `npm run dev` – dev server
- `npm run build` – typecheck (`tsc -b`) and production build into `dist/`
- `npm run preview` – serve the built site
- `npm run lint` – oxlint

## Structure
- `src/data/cv.ts` – **all content** (profile, contact, skills, jobs, projects). Edit text here, not in components.
- `src/components/*.tsx` – page sections (`hero`, `contact-section`, `skills-section`, `experience-timeline`, `interests-section`, `projects-section`, `site-header`).
- `src/components/ui/` – generated Magic UI / shadcn components. `App.tsx` renders a fixed, masked Magic UI `DotPattern` as the page background.
- `vite-plugins/seo.ts` – at build time injects a static HTML fallback of the CV (for crawlers without JS) and schema.org `Person` JSON-LD, both generated from `cv.ts`. Profile URLs (`sameAs`) come from `links` in `cv.ts`; add `linkedin` there. `public/robots.txt` and `public/sitemap.xml` are static.
- `src/data/github.json` – GitHub `logins` whose contributions are summed into the Activity heatmap. `src/data/contributions.json` is generated by `scripts/fetch-contributions.mjs` (CI refreshes it on every deploy and daily); refresh locally with `GITHUB_TOKEN=$(gh auth token) npm run fetch:contributions`.
- `src/assets/ari/` – photos of Ari for the Interests marquee (any `.jpg/.jpeg/.png/.webp`, picked up automatically, shown in color). Interest blurbs live in `interests` in `cv.ts`.
- `public/favicon.png` (256px) and `public/apple-touch-icon.png` (180px) – the Gravatar, downloaded from `https://gravatar.com/avatar/<sha256 of email>?s=<size>`; re-download to update.
- `src/assets/avatar.jpg` (lg+ screens) and `avatar_xs.jpg` (small screens) – hero images. `src/assets/profile.png` is the small avatar in the sticky header (square, ideally a transparent circle cut-out).

## Rules
- Add Magic UI components with the Magic UI MCP (`.mcp.json`) or `npx shadcn@latest add "https://magicui.design/r/<name>"`. Do not hand-edit files in `src/components/ui/` unless unavoidable.
- The hero image and the header avatar are made black & white in CSS (`grayscale` in `hero.tsx` / `site-header.tsx`). Never pre-process the images; just replace the files. Everything else uses color: the accent is the `brand` token (`text-brand`, `bg-brand`, defined in `src/index.css`), the icon cloud uses logo brand colors, the heatmap is GitHub green.
- Theme is the `dark` class on `<html>`, persisted in `localStorage["theme"]`; an inline script in `index.html` applies it before paint. Use shadcn tokens (`bg-background`, `text-muted-foreground`, ...) so both themes work.
- Deployment is only via `.github/workflows/deploy.yml` on push to `master`. Never commit `dist/`.
- Before finishing UI work, run `npm run build` and check light + dark mode and a phone-width viewport.
